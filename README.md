## GophKeeper — сервер и CLI‑клиент

Проект реализует простую систему менеджера секретов:

- **сервер** поднимает HTTP‑API, принимает запросы от клиентов, шифрует и хранит секреты пользователей в базе данных;
- **CLI‑клиент** работает из терминала, позволяет пользователю регистрироваться, логиниться и управлять своими секретами (пароли, заметки, бинарные данные, данные карт), отправляя запросы на сервер.

### Зависимости

- Go 1.25+
- Docker и docker-compose (для запуска Postgres)

### Запуск сервера локально

1. Поднять Postgres через docker-compose:

```bash
docker-compose up -d
```

2. Запустить сервер:

```bash
go run ./cmd/server
```

По умолчанию сервер слушает адрес из конфигурации (обычно `:8080`).

### Сборка и запуск CLI‑клиента

Собрать клиент:

```bash
go build -o gog-client ./cmd/client
```

Запустить клиент (интерактивная CLI):

```bash
./gog-client
```

Внутри CLI доступны команды:

- `register <login> <password>` — регистрация пользователя;
- `login <login> <password>` — вход;
- `logout` — выход;
- `secret-list` — список секретов;
- `secret-get <id>` — получить секрет по ID;
- `secret-create <type> [key=value ...]` — создать секрет;
- `secret-update <id> key=value [...]` — обновить секрет;
- `secret-delete <id>` — удалить секрет;
- `version` — показать версию и дату сборки клиента;
- `help` — краткая справка по командам.
